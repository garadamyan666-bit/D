# Trade Analysis Bot

Binance Spot շուկայի վերլուծության կայք՝ անձնական հաշիվներով, յուրաքանչյուր օգտատիրոջ առանձին պատմությամբ, ռիսկի կարգավորումներով և Telegram ծանուցումներով։ Կայքը միայն վերլուծում է և գործարք չի բացում կամ փակում։

## Հնարավորություններ

- Գրանցում և մուտք՝ պաշտպանված գաղտնաբառերով ու երկարատև անվտանգ session-ով
- Յուրաքանչյուր օգտատիրոջ պատմության և ծանուցումների ամբողջական մեկուսացում
- Binance-ի հանրային շուկայական տվյալներ՝ առանց Binance API key-ի
- M1 և M15 կանխատեսումների ստուգում միայն ադմինի վահանակում
- Անձնական հաշվեկշիռ և ռիսկի տոկոս՝ դիրքի չափի հաշվարկի համար
- Անձնական Telegram կապ, լեզու, շեմ և պարբերական ծանուցումներ
- Տեխնիկական վերլուծություն, շուկայի լրացուցիչ տվյալներ, առաջատարներ և backtest

## Տեղային գործարկում

```powershell
cd "C:\Users\user\Desktop\Trade Analize\trade-analysis-bot"
.\venv\Scripts\Activate.ps1
python run.py
```

Բացեք `http://127.0.0.1:8000/register`։ Նախկին ադմինի հաշիվը պահպանվել է, իսկ տվյալները գտնվում են `admin-access.txt` ֆայլում։

Telegram-ի համար `.env.example`-ից ստեղծեք `.env` և լրացրեք համապատասխան դաշտերը։ Երբեք մի հրապարակեք `.env`, `admin-access.txt` կամ տվյալների բազան։

## Թեստեր

```powershell
python -m pytest -q
```

Թեստերն աշխատում են առանձին ժամանակավոր բազայով և չեն փոփոխում իրական տվյալները։

## Հանրային տարբերակի կարևոր պայմաններ

Օգտագործեք HTTPS, `PUBLIC_URL`-ում գրեք վերջնական HTTPS հասցեն, Telegram-ի հարցումների համար պահեք մեկ worker, գաղտնի տվյալները տեղադրեք hosting-ի environment variables բաժնում և պարբերաբար backup արեք բազան։ Բազմաթիվ օգտատերերի դեպքում ցանկալի է անցնել կառավարվող PostgreSQL-ի։
